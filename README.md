DreamAchiever_App 🚀

     A simple goal-setting and achievement app that helps users create, track, and simulate their dreams or goals. The project includes a goal-simulation tool and a basic UI for planning progress.

Features

    Add and simulate goals

    Simple, clean interface

    Lightweight and easy to run

Install dependencies:

    npm install 

Running the Project :

     Backend:
     cd backend
     mvn spring-boot:run

     Frontend:
     cd frontend
     npm run dev
